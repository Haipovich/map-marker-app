# Map Markers — приложение с картой и изображениями

React Native + Expo (Expo Router, TypeScript). Долгое нажатие на карте добавляет маркер, нажатие на маркер открывает экран с деталями, где можно прикреплять и удалять изображения.

## Установка и запуск

```bash
npm install
npx expo install react-native-maps expo-image-picker   # подберёт версии под текущий SDK
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** (iOS/Android). Ключи Google API не нужны.

> Карта работает только на телефоне/эмуляторе. В браузере (`w`) показывается заглушка — `react-native-maps` не поддерживает web.

## Структура

```
src/
├── app/
│   ├── _layout.tsx        # Stack-навигация + MarkersProvider
│   ├── index.tsx          # экран карты
│   └── marker/[id].tsx    # экран деталей маркера
├── components/
│   ├── Map.tsx            # карта (native); Map.web.tsx — заглушка для браузера
│   ├── MarkerList.tsx     # лента маркеров внизу карты
│   └── ImageList.tsx      # сетка изображений с удалением
├── store/markers-context.tsx   # общее состояние маркеров (React Context)
└── types.ts               # интерфейсы TypeScript
```

## Принятые решения

- **Состояние** — React Context (`MarkersProvider`): оба экрана работают с одним списком маркеров. В навигацию передаётся только `id` маркера, а не сам объект (в URL нельзя класть сложные данные).
- **Типы** (`types.ts`): `MarkerData`, `MarkerImage`, `Coordinates`, `MarkerRouteParams`, `MarkersMapProps`.
- **Навигация** — Expo Router с типизированными маршрутами. Возврат: `router.back()`, а если истории нет — `router.replace('/')`.
- **Выбор изображений** — `expo-image-picker` (системная галерея, можно выбрать несколько фото).
- **Обработка ошибок**
  - загрузка карты: индикатор, по таймауту 15 с — сообщение и кнопка «Повторить»;
  - выбор изображений: `try/catch` + `Alert`;
  - навигация: `try/catch` вокруг `router.push` и экран «Маркер не найден».

## Известные ограничения

- Данные хранятся только в памяти: после перезапуска приложения маркеры и фото пропадают (можно добавить `AsyncStorage`).
- Названия маркеров автоматические («Маркер N»), редактирования нет.
- На web карта недоступна.
